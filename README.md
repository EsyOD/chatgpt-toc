# ChatGPT 提问目录

Chrome 扩展，在 ChatGPT 和 Codex 网页对话右下角添加一个提问目录。目录按对话顺序显示你发送的问题，支持搜索、点击定位和随滚动高亮。长提问以摘要呈现，提问里的代码使用等宽字体，搜索仍覆盖完整内容。点击右上角关闭按钮，或在目录内按 Esc，即可收起。

## 安装

1. 解压 ZIP，确认解压后的 `chatgpt-toc` 文件夹直接包含 `manifest.json`。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `chatgpt-toc` 文件夹。
4. 打开或刷新 ChatGPT 或 Codex 网页对话。点击右下角的「提问目录」。提问加载后会自动加入目录。

从旧版升级时，替换原扩展目录里的文件，在 `chrome://extensions` 重新加载扩展，再刷新对话。

## 自定义目录

可拖动目录按钮或展开后的标题栏移动位置，拖动面板边角的缩放手柄调整宽度及高度。打开目录并点击右上角的「外观设置」，可选择停靠角、调整水平和垂直边距、面板宽度及最大高度。设置保存在本机 Chrome，窄窗口会自动限制面板尺寸。点击「恢复默认」可还原布局。

## 权限和兼容性

需要 Chrome 105 或更新版本。扩展仅在 `chatgpt.com` 和旧入口 `chat.openai.com` 上运行。问题文字在当前页面内处理。扩展仅在本机存储目录外观设置，无网络请求或后台服务。

目录读取当前展示的对话分支。当 Codex 分段渲染长对话时，目录会保留已读取的提问。展开目录后可点击「读取完整对话」，扩展会逐段滚动读取，并在完成后返回原位置。若 ChatGPT 改变了消息的页面标记，扩展可能需要更新。
